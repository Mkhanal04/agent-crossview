How Crossview counts

Where Crossview's numbers come from, how it works out prices, and how they compare with the apps' own. It runs only on this Mac, and nothing it reads leaves the computer.

Back to Your week

What it reads

Counts and names only
  • The logs that Claude Code, Cowork and Codex keep on this Mac.For each reply it reads the time, the model, how much was read and written, and any subagent, skill or connector it used. It also reads chat titles and the folder each chat ran in, so it can group chats by project. At the start of a chat, Claude Code records every action each connector offers, and Crossview reads that list too. It doesn't read Claude's replies, and the only use of your messages is the counts described below.
  • The Claude app's own record of how much of your 5-hour and weekly limits you've used.
  • Your setup, which means the names and short descriptions of your subagents and skills, and the model a subagent's file asks for if it names one. It also reads the "ask" and "allow" rules and the on and off switches in Claude Code's settings, the names of your connectors and plugins, and how long each rule file is and when it last changed.A subagent is a separate AI that Claude Code hands part of a job to. A connector is a link to another app, like Google Drive or Figma. A rule file is a file of instructions Claude reads at the start of every chat. Crossview reads rule files to count their words and doesn't keep what they say.
  • For Your AI's instructions, it reads your rule files, your subagent and skill files, and Claude's notes about you. It counts their words, finds rules that repeat, checks that links and paths still lead somewhere, and sees how old each note is. From the logs, it reads which of those files loaded at the start of each chat. Files in your private folders are counted but never read.Claude Code calls rule files CLAUDE.md, and Codex calls them AGENTS.md. Claude's notes are what Claude saves about you between chats, in its memory folders.
  • For Codex, it reads the limit numbers Codex records after each reply (how much of its 5-hour and weekly limits you used, and when each resets), Codex's settings file, the AGENTS.md rule files in your project folders, and whether Codex keeps a notes file. It doesn't read what's in that notes file.
  • The messages you typed in Claude Code, because you said yes to this. Crossview counts how often you correct Claude and on what topics. It keeps the counts and never the text, and it skips your private folders.
  • Your project folders, to spot paid services outside your plans.It looks in settings files for the names of paid services' keys, such as "the Claude API key", and never reads the key itself. It also looks for code that calls those services.
  • Day-job and personal work.Folders on your private list show only as "Day job" or "Personal", without titles.

What it keeps

All of it in Crossview folder
  • Counts, names and titles, in a folder called data inside Crossview folder, plus one file the page reads. For Your AI's instructions, it also keeps a sentence from each rule that repeats across your files, and the exact lines of any change it prepares.Claude Code deletes a chat's log about 30 days after the chat was last used. Crossview keeps the counts it already made from that chat, so your history doesn't shrink. It never keeps the chat itself.
  • If you switch on the warning line in Claude Code, it keeps the time of each reading, how much of each limit you'd used and when each limit resets, in data/pace-log.jsonl.
  • Any chat you move to another project, and any monthly amounts you type in, in the same folder.
  • Anything you hid with Not now, in this browser only.
  • To remove everything, delete the data folder, and data.js and progress.js inside the app folder. The next refresh rebuilds them from the logs.

What it can change

Only what you say yes to
  • Which model a subagent uses. On Your week, "What used up my limit?" can add one line, model: sonnet, to the subagent files you tick. It only touches files in the .claude/agents folder in your home folder.
  • Which connector actions ask you first. "What can Claude reach outside my Mac?" can add rules to the "ask" list in ~/.claude/settings.json, so Claude Code asks you before it runs those actions. Nothing else in that file changes.
  • Nothing happens until you press "Make this change", and that button only works when you open Crossview with its file. Before each change, it saves a copy of the file in the data folder and writes down what changed.Undo, on the same card, takes out exactly what Crossview added and leaves anything you or Claude Code changed since. You can also edit the file yourself.
  • On Your AI's instructions, it can change two lines in your rule files about switching folders, and you see both lines word for word before you say yes. It can also move notes Claude hasn't changed in three months into an archive folder next to them, and take their lines out of that folder's index. Nothing is deleted, and Undo puts everything back.
  • "What have I set up that I never use?" changes nothing. Your Claude account's skills are switched off on claude.ai, so it gives you the list and tells you where to go.

What it sends

Nothing
  • Nothing leaves this Mac. The page loads no fonts, scripts or trackers from the internet.
  • When you open Crossview with its file, a small program starts on this Mac. It answers only this Mac, and it only accepts changes from its own page.
  • "Copy the request" for a bill only puts text on your clipboard. Nothing happens unless you paste it into Claude Code yourself, and Claude Code asks before each step.
  • The demo company is made up and holds nothing from your logs. Before it's shared, Crossview's checks scan every demo screen and file for names from your own data.

How can I check this myself?

Open Claude Code, type /usage and press w. It shows your plan's current 5-hour and weekly bars, which come from Anthropic, and lists the skills, subagents, plugins and connectors used most in the last 7 days. It keeps no past weeks, so it can only check this one. Crossview's week starts on Monday, while Claude Code's 7 days include last weekend, so the two can differ a little. Codex shows its own limits in Codex itself.

Every reply in all three apps is priced the same way, at the per-use prices Anthropic and OpenAI publish (last checked Oct 10, 2026). The pay-per-use price is what the same work would cost if you paid for each use. You pay a flat subscription, so it isn't your bill.
