# Glass Box voice note

The rule for every word on Glass Box's screens, hovers, buttons and sheets. Drafted Oct 14 2026 with the `screen-words` skill. Milan picked this voice on Oct 14 from one card written four ways (calm colleague, warm coach, crisp and minimal, patient teacher). What to avoid on top of it is the shared list, `_Knowledge/writing/ai-tells.md`.

## Who reads it
Someone at work who uses Claude Code, Cowork or Codex but doesn't build software: a marketer, a salesperson, a product manager. They know the apps and their plan. They don't know what CLAUDE.md, MCP or tokens are, and they shouldn't have to.

## How it sounds
Like a calm colleague who has looked over your setup and is telling you what they found, across a desk. On the four tone scales: serious, casual, respectful, matter-of-fact. Close to how Apple's Screen Time and Health apps talk to you. Never clever, never alarming, never cheerleading.

- Full sentences, the way you'd say them. Contractions are fine.
- The answer first, then the reason.
- One idea per sentence.
- Numbers sit in the number slot (the big figure, a bar, a table). Sentences stay plain.
- How a number was made goes in its hover or the footer, never in the main line.
- Card headings are the reader's own questions, in sentence case and normal type.
- Buttons say what happens next: "Show me the two lines", not "See the change".
- At most one "this, not that" sentence on a screen.
- No labels with colons in running text, no bold lead-ins like "Why:" in the middle of a paragraph.

## One name for each thing
Use these on every screen, in every hover and button. The first time a term appears on a screen, its hover explains it.

| Say | Explained as (first use) | Don't say |
|---|---|---|
| the apps (Claude Code, Cowork, Codex) | the AI apps you use | agents (for the apps), tools |
| subagent | Claude Code can hand part of a job to a subagent, a separate AI with its own instructions | helper, assistant, helper agent |
| skill | instructions packaged for one kind of task, which Claude or a subagent loads when that task comes up | |
| connector | a link to another app, like Google Drive or Figma (Claude's settings call these MCP servers) | port, integration |
| rule file | a file of instructions Claude reads at the start of every chat (Claude Code calls it CLAUDE.md) | instructions, guide |
| your main rule file | the one rule file every chat reads, in any folder | global CLAUDE.md |
| Claude's notes | what Claude saves about you between chats | memory (on its own), facts |
| project | one of your project folders | piece of work, work item |
| chat | one conversation | session |
| limit | the 5-hour and weekly caps on your plan | |
| pay-per-use price | what the same work would cost at published per-use prices | list price, API price |
| Not now | hides a suggestion for a week; the answer stays | Snooze, Dismiss |

## The first sentence on each tab
One sentence, one idea, one line: it answers the reader's question for that tab in plain words, with no tool names and no stacked facts. Its wording goes through the screen-words skill's comprehension test (copy deck: docs/copy-deck-leads-2026-10-15.md).

## Words to avoid
carrying, point at nothing, disagree (say contradict), lit, worked out by fixed rules, Ready for you, piece of work, helper, the receipt (outside the receipt itself), sends out.

No tag-on line after a finding that tells the reader how to feel about it or that it's for them: "That's the one thing that needs you", "N of the four questions need you", "Nothing needs you", "Needs you" as a label (his note, Oct 15). Say what was found; orange already marks what to act on.
